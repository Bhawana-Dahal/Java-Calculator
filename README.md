# NaturalNumber Calculator

A Java-based calculator application that performs operations on `NaturalNumber` values. The project is organized using the Model-View-Controller (MVC) design pattern to separate the user interface, application logic, and data/model components.
This was done as one of the projects for OSU's Software 1 course

## Features

* Performs calculations using `NaturalNumber` values
* Supports multiple arithmetic operations
* Uses separate model, view, and controller components
* Implements interfaces and classes to organize application functionality
* Includes custom implementations for the calculator's underlying components

## Technologies

* Java
* Object-Oriented Programming
* Model-View-Controller (MVC)
* Interfaces and Implementations
* NaturalNumber data type

## Project Structure

* **Model** — Handles the calculator's data and core operations
* **View** — Handles the user interface and displays results
* **Controller** — Coordinates user input and calculator operations
* **Implementations** — Provides concrete implementations of the calculator's interfaces

## Purpose

This project demonstrates object-oriented programming, abstraction, interfaces, implementation classes, and software design principles in Java.
